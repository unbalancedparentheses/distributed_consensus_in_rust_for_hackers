# Distributed Consensus in Rust for Hackers

A hands-on guide to understanding distributed consensus algorithms, from crash fault-tolerant protocols to Byzantine fault-tolerant systems and modern blockchain consensus.

**Read online:** [distributedconsensusinrustforhackers.com](https://distributedconsensusinrustforhackers.com)

## Topics Covered

- Distributed systems fundamentals and failure modes
- Replication and consistency models
- Replicated state machines
- Crash fault-tolerant (CFT) consensus
- Byzantine fault-tolerant (BFT) consensus
- Bitcoin and permissionless consensus
- Proof of Stake consensus
- DAG-based consensus
